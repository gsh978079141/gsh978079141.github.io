# Domain Redirector Privacy Policy

Last updated: June 10, 2026

## English

Domain Redirector is a Chrome extension used to redirect user-configured page requests from a source address to a target address.

### Data handled by the extension

The extension handles the following data only to provide its request redirecting feature:

- Redirect rules created by the user, including rule name, source address, target address, and enabled status.
- URLs of browser requests, only for local matching against the user's redirect rules.
- Domains detected on the current active tab when the user clicks the Detect button.

### Data storage

Redirect rules and the extension enabled status are stored locally in Chrome extension storage on the user's device. The extension does not operate a server and does not upload, sell, share, or transfer this data to the developer or to third parties.

### Data use

The extension uses request URLs and stored redirect rules only to determine whether a browser request should be redirected. The extension does not use user data for advertising, analytics, profiling, or any unrelated purpose.

### Data sharing

The extension does not share user data with the developer, advertisers, analytics providers, or other third parties.

### Remote code

The extension does not load or execute remotely hosted code.

### User control and deletion

Users can delete redirect rules in the extension popup. Users can also remove all locally stored extension data by uninstalling the extension or clearing the extension's storage in Chrome.

## 中文

Domain Redirector 是一个 Chrome 扩展，用于将用户配置的页面请求从源地址转发到目标地址。

### 扩展处理的数据

本扩展仅为实现请求转发功能而处理以下数据：

- 用户创建的转发规则，包括规则名称、源地址、目标地址和启用状态。
- 浏览器请求 URL，仅用于在本地与用户配置的转发规则进行匹配。
- 用户点击 Detect 按钮时，从当前活动标签页检测到的域名。

### 数据存储

转发规则和扩展开关状态仅保存在用户设备上的 Chrome 扩展本地存储中。本扩展不运营服务器，也不会将这些数据上传、出售、共享或转移给开发者或任何第三方。

### 数据用途

本扩展仅使用请求 URL 和本地保存的转发规则来判断浏览器请求是否需要被转发。本扩展不会将用户数据用于广告、分析、画像或任何无关用途。

### 数据共享

本扩展不会与开发者、广告商、分析服务商或其他第三方共享用户数据。

### 远程代码

本扩展不会加载或执行远程托管代码。

### 用户控制与删除

用户可以在扩展弹窗中删除转发规则。用户也可以通过卸载扩展或清除 Chrome 中该扩展的存储数据来删除所有本地保存的数据。
